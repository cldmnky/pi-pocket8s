Help and access

  • Agent endpoint: not configured
  • Access to the pi-pocket agent is governed upstream by pi-pocket invitations and roles. This portal does not manage users, roles, or invitations.
  • The agent's service account has namespace admin permissions in this namespace (requested configuration). Anything running in the agent can read and modify resources here, including the runtime secret.
